# Vokri Cards

Vokri Cards is a local-first flashcards app for learners of Finnish and Swedish. Its interface is English. Today offers daily reviews and new words from your enrolled vocabulary. Each recall direction has its own offline schedule. Full Vokri, the future structured-course product, will reuse the vocabulary, learning-domain, persistence and design foundations.

## Run on a phone or emulator

Use Node **24.22.2** and npm **11.19.1**. The lockfile resolves Expo **58.0.26**, React Native **0.88.1**, React **19.3.0** and Expo Router **58.0.32**. Install native packages with `npx expo install` so Expo selects compatible versions. Expo Router’s dependency tree uses the matching React DOM peer. Application targets are Android and iOS.

```sh
nvm use
npm ci
npm start
```

Open the project in a compatible Expo Go client for SDK 58. Scan the Metro QR code on a phone connected to the development machine’s network. For Android, start an Android Studio virtual device and run `npm run android`. For iOS, use a Mac with full Xcode and an installed Simulator runtime, then run `npm run ios`. App configuration uses the development slug `vokri-cards` and local scheme of the same name. The repository contains no store credentials.

## Current experience

- Choose Finnish (Suomi) or Swedish (Svenska) on first launch. Continue saves the choice on the device. Returning learners land on Today after preference hydration.
- Navigate Today, Discover and My Words. Today’s first-use action opens Discover. Discover offers curated decks, topic browsing, search, tier filters and word details for the active language.
- Add a word or choose members of a curated deck. Learn New offers up to five enrolled words in recognition, production or mixed direction. Reveal, rate, and optionally revisit. Today restores an unfinished session or its completion summary after restart.
- Open Settings from the header. Switch language from the header chip or Settings, and choose System, Light or Dark appearance. Changing language preserves appearance. Discover starts a fresh browsing context for the selected language.
- The native UI uses bundled Newsreader and Inter, local design icons, safe areas, scalable text and accessible selection controls. [Font licenses](assets/licenses) · [Multilingual design addendum](docs/handoff/vokri-cards/vokri-cards-multilingual-implementation-addendum.md)

## Checks

| Command | Result checked |
| --- | --- |
| `npm run typecheck` | Strict TypeScript across the app and tests |
| `npm run lint` | Expo ESLint rules |
| `npm test` | Preferences, Expo routes, file-backed SQLite learner state, the runtime registry and the Node ingestion pipeline |
| `npm run vocabulary:validate` | Source schemas, assignments, curriculum references and catalogue invariants |
| `npm run vocabulary:generate` | Regenerates the two runtime catalogues and manifest |
| `npm run vocabulary:check` | Checks generated bytes without writing. Add `-- --base origin/main` to check historical Finnish identities |
| `npx expo config --type public` | Resolved native Expo configuration |
| `npx expo install --check` | Dependency compatibility with the installed SDK |
| `npx expo-doctor` | Project and dependency health |
| `npm run bundle` | Android and iOS Metro exports in the ignored `dist/` directory |

GitHub Actions runs clean installation, vocabulary validation and reproducibility, type checking, linting, tests, Expo configuration and dependency checks, and both bundle exports for pull requests. [Android verification and screenshots](docs/handoff/vokri-cards/foundation-qa.md)

## Learning and vocabulary sources

Expo Router routes live in `app/`. Cards-specific screens and navigation composition live in `src/cards/`. Shared language and vocabulary references live in `src/domain/`, storage and state in `src/preferences/`, and navigation-independent controls and theme in `src/ui/`.

The shared vocabulary engine exposes 2,000 Finnish and 2,000 Swedish entries through stable references, language-scoped search, tier and topic filters, and optional grammar. Discover uses it for six curated decks and the complete bilingual catalogue.
