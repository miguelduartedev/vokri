# Shared vocabulary engine

Cards and full Vokri can resolve the same Finnish or Swedish item from the existing `VocabularyRef` pair of `languageId` and `wordId`. The catalogue works offline. Content, editorial metadata and learner preferences have independent lifecycles. A learner’s future enrolment, saved words and review history can store references without copying definitions.

## From CSV to native assets

The two curated CSVs are the editable lexical sources. The Finnish assignments supply the IDs absent from that CSV. Node 24 reads strict UTF-8, parses each complete CSV record (including BOM, quoted commas, quotes and line breaks), checks the header and validates the fields for its language. It checks mappings, curriculum references, normalized items, unique IDs and the ranked tier boundaries before publishing any output. [Source files and attribution](../curriculum/vocabulary) · [Generator](../../scripts/vocabulary/generate.ts)

The generator writes one UTF-8 JSON array per language, one entry per line in pedagogical rank order. A small manifest records schema version, languages, counts, source names and digests, generated bytes and digests, attribution paths, and Finnish mapping version and digest. The hashes cover exact file bytes. Git preserves the original source line endings and the generated LF convention across checkouts. [Generated assets and manifest](../../src/content/vocabulary/generated)

### Source columns and normalized fields

| Source columns | Runtime representation |
| --- | --- |
| Both · `lemma`, `english`, `part_of_speech`, `rank`, `tier`, `topic`, `usefulness_score` | `lemma`, `english`, `partOfSpeech`, `rank`, `tier`, `topic`, `usefulnessScore`. Rank, tier and score describe editorial teaching order. |
| Both · `spoken_forms`, `notes` | Optional `spokenForms` and `notes` preserve source text, including punctuation and usage labels. |
| `example_fi` or `example_sv`, plus `example_en` | `example.learning` and `example.english`. The shared schema permits an absent example. Both current source editions require the pair. |
| Finnish · `original_frequency_rank` | Optional positive `provenance.originalFrequencyRank` from the retained frequency backbone. The adapter supplies `languageId: 'fi'`, the assigned `wordId`, the lemma as `displayForm` and the dataset identifier. |
| Swedish · `language_id`, `word_id`, `display_form` | `languageId`, `wordId`, `displayForm` verbatim. A bare display expression can still have a supplied gender. |
| Swedish · `noun_gender`, `definite_singular`, `plural_indefinite`, `plural_definite` | `noun.gender` (`en` or `ett`), `definiteSingular`, `indefinitePlural`, `definitePlural` under the optional noun object. |
| Swedish · `verb_present`, `verb_past`, `verb_supine`, `adjective_neuter`, `adjective_plural` | Optional `verb.{present,past,supine}` (past is preterite) and `adjective.{neuter,plural}`. Each part of speech receives only its supplied forms. Empty cells produce absent properties. |
| Swedish · `source_status`, `original_kelly_id`, `original_kelly_frequency`, `original_kelly_cefr` | `provenance.sourceStatus` and optional `provenance.kelly.{id,frequency,frequencyKind,cefr}`, alongside the dataset identifier. The frequency retains its comma-decimal string. The synthetic marker and source flag must agree. |
| Swedish · `qa_flags` | `editorial.flags` preserves the ordered, semicolon-delimited source warnings. |

The common schema separately records review of gloss, example and morphology, plus public-teaching approval. A generated record has passed structural validation and is available for internal preview. All current glosses and examples are unreviewed. Supplied Swedish morphology is unreviewed, and absent morphology is marked `not-supplied`. All public-teaching decisions are pending. ## Identity and corrections

**Finnish.** The checked-in assignment file keys each entry by NFC lemma, part of speech and an optional permanent sense discriminator. Its initial allocation reserved authored IDs first, including `minä → vocab.mina` and `ystävä → vocab.ystava`. Other entries received `vocab.<lowercase NFC lemma>` after collision checks. Subsequent generations only read assignments. The importer rejects duplicate keys, reused IDs, unassigned source rows, ambiguous rows and unused assignments. Diacritics distinguish `pelata` from `pelätä` and `vaara` from `väärä`. [Assignment file](../../scripts/vocabulary/finnish-identities.json)

**Swedish.** The imported `word_id` is opaque and permanent. A revised rank, translation, article or inflection has no effect on that ID. Preserve it when correcting a source record. For example `{ languageId: 'sv', wordId: 'sv-bok-9992bfa7' }` names `bok`, displayed as `en bok`.

**Curriculum.** Each import checks the eight authored unit inventories and their explicit vocabulary references. A small Finnish curriculum resolver handles two documented prose spellings. Recognition, production, phrase use and lesson-specific inflections can point to one lexical item. For example `haluan` is a teaching form of `haluta`, whose source spoken forms are `haluun; haluut`. A future course can supply its own approved example, form or sense in the lesson. [Compatibility coverage](vocabulary-engine-validation.md) · [Curriculum resolver](../../src/domain/vocabulary/curriculum.ts)

For a content update:

1. Edit the relevant source cell and retain the assigned ID. For a Finnish spelling or POS correction, update the current key and record the former key under `previousKeys` on the same assignment. Historical keys remain reserved. CI compares assignments against the PR base commit.
2. For a new Finnish item, check curriculum declarations and existing assignments before reserving an unused ID. Add one explicit mapping. A new Swedish item needs an explicit permanent ID in its source. Any future expansion beyond this edition must revise its count and tier contract in the same change.
3. If two rows share a Finnish NFC lemma and POS, the current CSV lacks a stable sense column. Resolve the ambiguity editorially and supply an explicit source discriminator and matching assignments before importing that edition. The importer will stop at this boundary.
4. Regenerate, inspect the source and generated changes together, run the checks below and commit the inputs, assignments and generated outputs together.

```sh
npm ci
npm run vocabulary:validate
npm run vocabulary:generate
npm run vocabulary:check -- --base origin/main
npm test
```

`validate` builds in memory and reports errors. `generate` stages validated output and publishes the manifest last. `check` rebuilds in memory and fails on extra, missing or byte-different output. Its optional Git base also detects removed or reassigned Finnish IDs. The initial edition establishes the baseline. CI runs this non-writing check alongside the existing mobile checks.

## Runtime API

```ts
import {
  getVocabularyItem, getVocabulary, getVocabularyCount, getVocabularyByTier,
  getVocabularyByTopic, searchVocabulary, vocabularyLanguages,
} from '@/domain/vocabulary/registry';

const hits = searchVocabulary('sv', 'en bok');
const book = getVocabularyItem({ languageId: 'sv', wordId: 'sv-bok-9992bfa7' });
if (book?.languageId === 'sv') {
  const plural = book.noun?.indefinitePlural; // böcker
}
```

`vocabularyLanguages` lists the supported language IDs. `getVocabularyCount` can read counts from the manifest before loading items. `getVocabulary` and the tier/topic filters return frozen, rank-ordered items. `getVocabularyItem` validates external references and returns `undefined` for a malformed, unknown or wrong-language reference. Other catalogue operations take a typed, explicit learning language.

Metro resolves the two static asset paths. The first request for a language freezes its data and builds an ID map and a small searchable index. Search compares trimmed, NFC-normalized, lowercased substrings within lemma, display expression and English meaning, returning each matching reference once in rank order. Blank or unmatched queries return an empty list. No router, preference store, filesystem, CSV parser or network service participates in a lookup. [Registry](../../src/domain/vocabulary/registry.ts)

## Editorial and product handoff

Finnish retains Daniel Radice’s Yle/Kotus-derived frequency information. Its ranking, glosses, spoken annotations and bilingual examples are curated. Swedish retains Kelly metadata from Elena Volodina and Sofie Johansson Kokkinakis, Språkbanken Text / University of Gothenburg. Its pedagogical ranking, added entries and AI-authored examples have separate provenance. The source notes describe CC BY 4.0 for the Finnish backbone and the specific Swedish Kelly XML. Before public distribution, review the exact source and downstream terms, attribution, translations, examples and applicable forms with qualified editors.
